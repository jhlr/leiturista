## 4. CÓDIGO NOVO NESTA SESSÃO
- src/leiturista/distribuidora.py (MÓDULO NOVO)
  - load_rows(): parseia os 4 CSVs, mantém foto existente; coluna leitura = só dígitos
  - _reading_candidate(ocr, img_bgr, label): roda det (PP-OCRv5) normal+invertido,
    merge de quads, crop, rec (PP-OCRv6) p/ classificar 'leitura'; filtra 3..8 dígitos
    (mata placas de identidade ~10 díg e datas 8 díg); escolhe o crop com maior
    _digit_match (dígitos alinhados à direita) vs rótulo; aceita match>=0.5
  - filtro de nitidez: variância do Laplaciano >= 25.0 (LAPLACIAN_LEGIBLE)
  - build_dataset(out_dir,...): gera crops .png + labels.csv (split train/valid/test
    80/10/10, seed=42) + manifest.csv (auditoria) + _qa/aceitos.png e _qa/rejeitados.png
  - NÃO roda TrOCR (caro); usa só det+rec ONNX (rápido)
- src/leiturista/cli.py: novo subcomando `import-distribuidora`
    .venv\Scripts\python.exe -m leiturista.cli import-distribuidora [-o data/distribuidora_amr]
      [--notes NA] [--min-sharpness 25] [-n MAX] [--seed 42] [--qa-n 40]

## 9. ARMADILHAS CONHECIDAS
- CLI/AGENTS usam .venv/bin (Linux) — no Windows usar .venv\Scripts\.
- PowerShell 5.1 não tem &&; usar `;` ou `cmd1; if ($?) { cmd2 }`.
- print de chars unicode quebra em cp1252 (scripts de debug) — evitar em prints.
- pandas read_csv NÃO usar keep_default_na padrão p/ "NA" (vira NaN); usar keep_default_na=False.
- processor do TrOCR é DeiTImageProcessor que redimensiona p/ 384x384 (estica aspecto) —
  comportamento consistente treino/inferência (crops wide esticados). Não "corrigir".
- `_trocr_recognize` faz upscale de crops pequenos (<160w ou <48h) antes do processor.
- load_trocr do trocr-small-printed loga MISSING encoder.pooler.dense (esperado, ignorável).
